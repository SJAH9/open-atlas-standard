# Governance

Maintainer and originating author: Sid J.A. Hubbard (SJAH9).

This proposed standard is developed in the open. Changes should distinguish
contract requirements, reference implementation behavior, and example research.
Submit a reproducible issue or pull request with affected inputs and expected
outputs. Do not publish confidential data in issues.

Breaking field/meaning changes require a new contract version and migration
notes. Data corrections require dated source/version changes and a release
note. Analytical disagreements must not be resolved by silently changing the
meaning of a source model. Automated validation is a minimum contract check,
not scientific peer review or external standards endorsement.

Organizations using the template should name their editorial reviewer, source
rights owner, release authority, and correction process. Individuals should
record the same responsibilities even if one maintainer carries all of them.
