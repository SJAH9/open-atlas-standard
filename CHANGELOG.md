- Proposed Open Atlas package standard, JSON Schema and semantic validator.
- Fresh three-project audit with exact upstream commit/README locks.
- Forty-six source discovery records with capability, provenance and rights.
- Individual and organization templates with intentionally empty evidence.
- Canonical package to static web atlas, vector PDF, CSV and GeoJSON.
- Country indicator and provisional event/point reference publications.
- Explicit CSV, WDI, RTLDI, War Maps and life-support import boundaries.
- One bounded, explicit World Bank live-fetch connector; no hidden refreshes.
- Local source inspector, exact-period links, register alternative, day/night,
  fullscreen and scoped offline app shell.
- Validation tests, browser QA script and Python 3.10/3.12 CI.

Original software/documentation MIT. Source data keep their own terms. This is
an author-proposed reference release, not external standards endorsement or a
replacement for the three founding atlases.
